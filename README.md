# 무붕 공간

무붕의 합주실 예약·멤버와 팀 등록·공지·위키 사이트입니다. 구글 캘린더 연결 없이 로컬에서는 SQLite, 공개 배포에서는 Supabase PostgreSQL에 저장합니다. 제공받은 검정·크롬 로고를 적용했습니다.

## 시작하기

Mac에서는 `start.command`를 실행하고 `http://127.0.0.1:4318`을 엽니다. 첫 실행에 운영진 계정을 만든 뒤 **멤버·팀 관리 → 엑셀 양식 다운로드 → 파일 검토 → 일괄 등록**을 이용합니다. 기존 서비스의 계정·예약은 자동 이전되지 않습니다.

`start.command`는 브라우저를 자동으로 엽니다. 이미 무붕 서버가 켜져 있으면 새 서버를 만들지 않고 기존 사이트를 엽니다. `EADDRINUSE`는 포트가 사용 중이라는 뜻으로, 기존 버전을 실행했다면 위 주소에 바로 접속하세요. 서버를 처음 켠 터미널에서 Ctrl+C를 누르면 종료됩니다.

다른 환경은 Node.js 24 이상과 Python 3.10 이상이 필요합니다. 배포용 PostgreSQL 연결에는 `npm ci --omit=dev`로 패키지를 설치합니다. 로컬 SQLite는 `node server.mjs`로 실행합니다. `PORT`, `PYTHON_BIN`, `DATA_DIR` 환경변수를 지원합니다. 인터넷 공개 운영은 [DEPLOYMENT.md](DEPLOYMENT.md)를 참고하세요.

## 엑셀 양식 (기존 파일 유지)

- 멤버: **아이디, 이름, 비밀번호, 세션, 기수, 전화번호, 팀, 관리자여부**
- 팀: **팀명, 보컬, 기타1, 기타2, 베이스, 드럼, 키보드**
- 신규 아이디 빈칸은 이름, 신규 비밀번호 빈칸은 `20000000`입니다. 처음 로그인할 때 비밀번호를 변경합니다. 기존 멤버의 빈 비밀번호는 현재 비밀번호를 유지합니다.
- 멤버 시트의 **팀은 빈칸**으로 둡니다. 팀 시트 각 파트에 멤버 아이디를 입력하면 해당 멤버의 팀 목록이 자동으로 채워집니다. 다른 팀으로 옮기거나 공석으로 바꾸면 소속도 자동 갱신됩니다. 여러 팀·파트 겸임을 지원합니다.
- 팀은 팀명, 멤버는 아이디로 기존/신규를 구분합니다. 동명이인은 아이디를 다르게 입력하세요. 전화번호는 텍스트로 입력해 앞의 0을 보존하세요.
- 팀의 공석은 빈칸입니다. 기존 팀 행의 빈칸은 해당 자리를 비웁니다. 파일에 없는 기존 멤버·팀은 자동 삭제하지 않습니다.
- 기존 멤버의 빈 관리자여부는 권한 유지, 신규는 일반부원입니다. Y/N으로 권한을 지정합니다. 현재 운영진 본인의 권한 해제는 막습니다. 다른 일반 정보의 빈칸은 그 정보를 비웁니다.
- 검토 화면에 소속 팀 변경, 권한 변경, 오류가 표시됩니다. 검토는 10분 후 만료됩니다. `.xlsx` 4MB 이하, 시트별 1,000행까지, 수식 셀은 지원하지 않습니다.

## 예약

- 한국 시간 **08:00–24:00**, 30분 단위. 모바일에서도 7일 주간표를 보고 예약합니다. ‘넓게 보기’로 가로 스크롤할 수 있고 예약 창 안에도 주간표가 표시됩니다.
- 기본 한도는 개인 주 3시간, 팀 주 6시간, 연속 3시간, 4주 앞까지입니다. 운영진이 조정할 수 있습니다. 예약 화면에 팀별 사용 시간과 한도를 표시합니다.
- 팀 합주는 해당 팀 소속 멤버가 예약합니다. 팀 목록은 이름순, 멤버 목록은 이름·기수·세션 기준 오름/내림차순으로 정렬합니다.
- 팀 예약에서 ‘매주 반복’을 선택하고 마지막 날짜를 지정하면 해당 날짜까지(포함) 같은 요일·시간에 등록됩니다. 첫 날짜는 예약 가능 기간 안이어야 하며 반복 종료는 최대 1년입니다. 운영진의 정기예약 마감일도 적용합니다.
- 반복 중 한 날짜라도 충돌하거나 한도를 넘으면 **전체 등록을 취소**합니다. 반복 예약 취소는 선택한 한 회에만 적용됩니다.
- 일반부원은 시작 전의 본인·소속 팀 예약을 취소합니다. ‘일반 부원의 당일 취소 제한’을 켜면 한국 날짜 기준 당일에는 운영진만 취소합니다. 운영진은 전체 예약을 취소할 수 있습니다.

## 공지·무붕 위키

운영진이 작성·수정·상단 고정하며 로그인한 부원이 읽습니다. 부원 사용법 공지를 최초 1회 자동 등록하고, 관리 메뉴에 운영진 사용법을 제공합니다. 기존 게시물은 덮어쓰지 않습니다.

본문의 http/https 주소는 클릭 가능한 링크가 됩니다. 공지와 위키에 파일당 10MB, 게시물당 5개까지 PDF·이미지·문서·엑셀·ZIP을 첨부할 수 있습니다.

**노션 가져오기:** 노션에서 HTML 형식으로 내보낸 뒤 위키의 ‘노션 가져오기’에 `.html` 또는 `.zip`을 올립니다. 이미지를 포함하려면 내보낸 ZIP을 그대로 올리세요. 여러 페이지가 있으면 가져올 페이지를 선택합니다. 제목·본문·표·목록·이미지와 지원되는 서식을 보존하는 복사본입니다. 노션의 실시간 동기화, 데이터베이스 기능, 임베드 앱, 하위 페이지 간 연결은 재현하지 않습니다. 하위 페이지는 각각 가져오세요. 원본을 계속 보려면 위키 문서의 ‘노션·원문 주소’를 등록합니다.

## 운영진 비밀번호 관리

멤버 목록의 **재설정**에서 임시 비밀번호를 직접 입력하거나 자동 생성합니다. 보기·복사 버튼을 제공하며 저장 시 운영진 본인의 현재 비밀번호를 확인합니다. 대상 멤버의 기존 로그인을 모두 해제하고 다음 로그인에서 변경하도록 합니다. 기존 비밀번호는 해시만 저장하므로 조회할 수 없습니다. 임시 비밀번호는 저장 완료 창을 닫으면 재조회할 수 없습니다. 운영진 본인의 행에는 **내 비밀번호 변경**이 표시됩니다. 엑셀 양식은 변경하지 않았습니다.

## 저장·백업

공개 배포는 `render.yaml`로 Render Free에 올리고 Supabase Session pooler 연결 주소를 `DATABASE_URL`로 입력합니다. 멤버·예약·첨부파일·위키 이미지는 모두 Supabase DB에 저장합니다. 실제 운영 데이터는 이 배포 파일에 포함되지 않습니다. 배포·이전·백업의 순서는 [DEPLOYMENT.md](DEPLOYMENT.md)에 있습니다.

로컬 기본 DB는 `data/mooboong.sqlite`입니다. 로컬에서는 `node backup.mjs`, PostgreSQL에서는 `node --env-file=.env transfer-data.mjs export 날짜.backup.json`을 사용합니다. 복구는 빈 PostgreSQL DB에만 허용됩니다.

## 검증

`npm ci` 후 `node --test tests/*.test.mjs`와 `python3 -m unittest discover -s tests -p '*_test.py'`로 인증, 엑셀 등록/팀 자동 소속, 예약 충돌·반복 원자성·시간 한도, 당일 취소 정책, 공지/첨부 권한, HTML 가져오기 안전 처리를 검사합니다.

공개 호스팅은 아직 연결하지 않았습니다. 로컬 주소는 다른 사람에게 공유해도 접속할 수 없습니다. 아이콘 라이선스는 `LICENSES.md`에 있습니다.
